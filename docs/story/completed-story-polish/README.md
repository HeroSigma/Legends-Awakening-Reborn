# Completed-story dialogue polish

This pass reviews the story already implemented: the Littleroot introduction and next-door family, Birch/Red rescue and lab scenes, Route 103, the Route 102 call and Timeless Woods encounter, Norman/Wally/Ralts, the Woods Triad, Rusturf and Briney, and Rustboro/Devon through the basement introduction. Untouched future scenes and generic world dialogue are outside this pass.

97 existing dialogue entries are revised. Pokémon, Pokédex, PokéNav, character/place names and item references use consistent spelling and capitalization. Red speaks more naturally, Brendan keeps his competitive humor, Wally stays tentative, and Norman encourages the player as a mentor. The player still asks questions and responds aloud. The new starter reaction still names the actual starter; Red still receives Charmander. Giovanni's R, Cyrus's G, the rift item, Colress and Elara's private Caelum thought remain intact.

Continuity fixes include returning to Birch rather than bringing him nonexistent notes, clearer descriptions of the stolen object and research, and consistent Devon Parts terminology. Wally's borrowed-Pokémon reaction and Norman's Poké Ball explanation now have separate speaker boxes so their colors and portraits are correct. The original received-item narration is retained. The Pokévial's three charges and the scientist's 50/150 shard explanation are unchanged in meaning.

All progression commands, movement, battles, flags and reward operations match the preceding release. Only the two extra speaker-separated presentation messages are added to the original message order. No maps, teams, save format or rewards are changed.

Validation checks the script commands against release 4b4d20d2e3 and measures dialogue with the game's own font using a seven-W player name and Rockruff's starter name. Native scene tests cover Petalburg/Wally, Woods loss/retry, Rustboro's call and basement, Rusturf/Briney, Littleroot/Route 103, next-door staging and the Timeless Woods scenes. Saves used for checks are disposable. Reports identify their ROM; battle-outcome injection is disclosed where used.

Going forward, each newly authored scene gets dialogue, speaker/color, text-fit, staging and progression review as part of implementation. This is also recorded in the project's AGENTS.md.

# Dynamax Band unlock and selection

The Dynamax Band is the player unlock for ordinary battles. No stadium/map flag is required. Owning the Band works for existing saves as well as newly acquired Bands. Without it, player Dynamax remains unavailable. Held Mega Stones and Z-Crystals still prevent Dynamax; the native species and once-per-trainer restrictions remain.

In the move menu, SELECT cycles eligible gimmicks and START toggles the currently displayed gimmick. This preserves access to Tera after obtaining the Band. Move description remains on L. The cycle control is active with the configured modern move-rearrangement rules.

Ordinary curated trainers now receive a stable Tera, Z-Move or Dynamax assignment derived from their identity and the player Trainer ID. Gym leaders retain their per-attempt random choice and eligible Mega option. The designated team member must enter battle and survive to use it; every opening Pokémon does not Dynamax.

Native validation uses a disposable save and an actual Calvin battle. It covers Band ownership, held-item restrictions, trainer ace eligibility and real move-menu SELECT/START input. See dynamax-band-validation.json.

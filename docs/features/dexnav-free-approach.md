# DexNav free approach

Approach DexNav targets by walking or sprinting without holding A. Movement speed, including bicycles, no longer scares away a search target or breaks its chain. Contact with the target tile starts the normal DexNav battle automatically.

Search selection/registration remains manual. Timeout, leaving signal range, map changes, and native cave/water relocation remain unchanged. No encounter, equipment, level, shiny or save data changes. Optional slow creeping is still available.

# TM51?100

Adds the accepted fifty-move list, from TM51 Roost to TM100 Tera Blast. TM01?50, all raw item IDs and the eight HMs remain unchanged. Existing saves need no reset.

The TM macro supplies native move lookup, numbering and type-based TM icons. Each item has a readable description and a base price of 4,000?15,000. Legends Store applies its existing markup/sales and one-owned-copy sold-out rule. TMs remain reusable after teaching; HMs remain excluded from the Store. Fill Bag uses the now-valid machine mappings.

Species compatibility is regenerated by the existing Expansion learnset helper from the repository's canonical learnables and teaching rules. The new TMs are not universal permissions. See `tm51-100.json` for all assigned moves, base prices and descriptions.

Validation: 569 native TM checks, including each new mapping, species compatibility sample, price, icon, description, purchase, sold-out status, HM exclusion, incompatible Magikarp checks and a real Bag-to-Charizard Roost lesson that retains the TM. The existing Legends Store suite passes 940 checks. Tests use an isolated emulator battery, never the player's save.

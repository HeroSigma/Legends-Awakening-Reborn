# Sapphire May palette trial

May's Hyper rival front portrait is used by both dialogue mugshots and battle
introductions. Its red outfit/bow/shoe accents now use sapphire blue. Her hair,
skin, yellow and green accents stay unchanged. The held Pok? Ball keeps its red
colors using previously unused palette indices 3 and 4.

The full Hyper overworld walking sheet uses the same blue pair. It now owns
palette tag 0xDB80 and a palette generated from its own PNG, rather than sharing
Brendan's 0xDB40 palette. Brendan and player customization palettes are unchanged.
No sprite dimensions, frames or animation tables are modified.

Blue pair: light RGB(49,115,239), dark RGB(24,57,156), quantized by the GBA asset
compiler. Verified unchanged hair/skin pixels against main; compiled and checked
with the native Mt. Chimney backup scene and May's field dialogue.

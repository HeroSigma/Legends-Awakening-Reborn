# Aren / Aria complete overworld and trainer artwork canary

Aren uses the user's corrected action sheets from Downloads/Legends-Awakening-Reborn/protagonist-previews/Your-Aren/Aren-action-draft/Aren-actions. Aria uses the reviewed Aria action draft. Both are now connected as playable characters for walking, running, Mach Bike, Acro Bike, Surf, fishing, watering, field moves, underwater and decorating. Native action frame sizes, order, timings and identities are retained. Aren's corrected pixel indices and palettes are checked against the current user files; Aria's against its reviewed sources. Transparency metadata is normalized to index zero. No original source files in the user editing folders are overwritten.

Normal/action player palettes are isolated per protagonist. Underwater retains the dedicated native blue palette. Special player field effects request the protagonist palette through LoadPlayerObjectEventPalette. Original Brendan/May files remain available, and Ruby Brendan/May overworld rival pointers are preserved.

Trainer fronts are 64x64; backs are four vertically stacked 64x64 frames. New TRAINER_PIC_AREN/ARIA entries are appended to preserve existing trainer IDs; original Brendan/May trainer fronts and backs remain unchanged. The Emerald player selection helper selects the new entries, while original Ruby/Kanto version selection remains intact. A custom back animation uses the generated neutral/windup/extension/release ordering with the original Hoenn timing; idle shows neutral instead of release. Front and back share one 16-entry palette per character.

Trainer draft generated with the built-in imagegen tool. Reference images: user concept sheet, original Brendan trainer front, original four-frame back. Prompt requested a transparent five-column by two-row atlas: one full-body front and four upper-body back throwing poses for Aren, then Aria; crisp Emerald pixel style, <=15 opaque colors per character; preserve black/silver hair, green accents and dark trousers for Aren, brown/pale-streak long hair, green clip, shorts and matching jacket for Aria. Source: generated_trainer_atlas.png. Final assets are stored in graphics/trainers/{front_pics,back_pics,palettes}/{aren,aria}.*. Native conversion crops the atlas, scales into 64x64 frames and encodes a shared indexed palette. This is an in-game artwork canary, not a claim of pixel-exact concept reproduction.

Validation: format_validation.json checks indexed format and approved-source preservation. runtime_validation.json checks exact linked action bytes, all player graphics/palette bindings, front/back trainer table isolation, native front-sprite loading and both disposable battle introductions through the command menu. Native mGBA uses isolated new saves; the user's battery save is never loaded by tests. Bedroom, next-door and complete intro checks cover both player genders. Screenshots show native front loader tests in the bedroom and actual battle intros. Runtime action screenshots force each graphic on the player; they are rendering checks, not end-to-end tests of every fishing/bike/field-move interaction.

No map/story data, flags, variables or save fields were changed by this artwork integration. Manual follow-up: visually review trick poses, fishing rods, water/bridge reflections and special field effects during normal gameplay; refine the draft art as desired. No battle logic, trainer teams, encounters or progression changes.

# Native redraw trial

Review only. No playable graphics, ROM or save were changed.

Built-in imagegen used the concept sheet for Aren/Aria identity and the original Brendan walking sheet for proportions/style. Prompt requested true 16x32 logical pixels, compact Emerald proportions, fifteen opaque colors, and a 3-column by 6-row atlas: down/up/left for Aren then Aria; columns idle/left step/right step. The left idle specifically requires feet together and arms at rest.

redraw_draft.png is the generated draft. *_native.png are 16x32-cell conversion trials; *_native_6x.png show those cells enlarged six times. These are not approved native sprites: the generator still produces detail beyond the requested logical grid and native conversion can lose features. Compare the actual native previews, not only the large draft, before integration.

# Aria overworld action draft

Native indexed sheets based on May's original poses and the pixel-authored Aria standing/walking design: long brown hair, pale streak, green clip and black/white/green clothing.

Contains 88 frames across walking, running, Mach Bike, Acro Bike, Surf, fishing, watering, field moves, underwater and decorating. Each native PNG keeps the original action canvas and frame count. Indexed colors are limited to sixteen entries; index zero is transparent. Underwater uses its original blue palette, with Aria crown artwork instead of May's bow. Other actions use Aria's custom palette.

Edit the PNGs named after actions. *_preview_4x.png are enlarged contact sheets, not import sources. *_frames.gif cycle all source frames for inspection, not exact in-game animation sequence or timing. Native animation tables still control direction, frame order and speed.

This is a review draft. Unusual pose/head alignment and equipment overlap, especially tricks, field moves and underwater, should be checked visually before integration. action_audit.json lists the template matching scores and review hints; these do not certify visual quality. Validation confirms dimensions, frame counts, indexed color limits, transparency and nonempty frames. No ROM or save was changed. Aren's user-corrected assets are untouched. Battle sprites and menu portraits are separate work.

# Aren additional action draft

Based on the user-edited /home/allan/projects/walking.png. Original file preserved as walking_user_original.png in the parent folder.

Includes running, Mach Bike, Acro Bike, Surf, fishing, watering, field-move animation, underwater and decorating; walking.png is included for context. These are native indexed sheets with the original frame count/order/canvas size. Side-facing directions use each native action template, preserving equipment and pose geometry as far as the automated adaptation allows. Underwater retains the dedicated original blue palette.

Review-only: no playable assets, ROM or save were changed. This pack is for Aren only. Aria and battle/menu artwork are not part of this pack.

PNG files without a suffix are editable native sheets. *_preview_4x.png are enlarged contact sheets; do not import those. *_frames.gif cycles through all source frames for inspection, NOT the exact in-game action sequence/timing (many sheets contain several different animations).

All 79 action frames received the draft adaptation. The action_audit.json adapted field means a transformation was applied, not that visual quality or runtime behavior has passed. Unusual poses, especially Acro Bike tricks, field-move throwing poses and underwater, require visual review. Geometry/equipment checks here are limited to source frame format and visual contact-sheet inspection, not in-game validation.

Format validation passed: native dimensions, frame counts, indexed colors <=16, and original per-action palettes preserved.

# Native pixel-authored player trial

These native pixel-authored sprites are now installed in the normal player graphics. The paired save is preserved.

These frames use the original playable Brendan and May indexed 144x32 sheets as their pose/body template. Hair silhouettes, silver streak/green clip, outfit panels, green trim and palettes are authored directly as native pixels. No generated high-resolution illustration was reduced to produce these sprites. Native south/north/west idle and paired walking indices are preserved; east is intended to use the existing engine mirror.

aren_idle_8x.png and aria_idle_8x.png show down/up/left idle frames at exact eight-times enlargement. *_south.gif, *_north.gif and *_west.gif preview the native step/idle/alternate-step/idle cycle. The original animation timing will still be controlled by the game upon integration.

Remaining design polish: bring more of the concept jacket/satchel detail into the tiny pixel budget; refine hair asymmetry and long-hair movement. This trial is a template-based sprite redraw, not a pixel-exact match to the detailed concept illustration. Installed for user in-game visual review; other movement and battle artwork still uses existing assets.

# Donor portrait gallery

Open gallery.html to browse the available source-native HnS front pictures and recovered trainer front tables from Hyper Emerald, BWA, Sword/Shield Ultimate Plus, Aesthetic Red, Mercury and Stone Dragon 3. Original donor duplicates and alternate/animated sheets are retained. Only confirmed names are labeled; use the donor/set/index for selections.

The manifest records coverage, exact ROM hashes, table/palette offsets and extraction errors. GS Chronicles cannot be recovered because the original ROM is absent. Mercury has one unsupported entry; it is recorded rather than fabricated. Archive sources are used when the original download was removed.

These pictures are reference artwork only: creating the gallery adds no portraits, gameplay or donor ROM data to the playable build. Credits remain with the donor projects, their artists, and the original Pokémon/Game Freak artwork. HnS source is from the local canary source checkout. Rebuild with tools/la_world/importers/amap/build_donor_portrait_gallery.py.

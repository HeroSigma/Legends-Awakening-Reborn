User confirmed that Style must change the garment design while preserving Aren
and Aria's own hair and face. Existing character colorways are not new garments.
This image is a concept reference, not a native 64x64 or indexed 4bpp game asset.
The playable ROM has not been changed for this design trial.

collar, front panels, pockets and seam shading. Aren wears jeans; Aria keeps shorts.
Preserve the protagonists' original head and facial pixels in production assets.
The generated concept is only a reference for the clothing, not a replacement head.

Production still needs native front/back portraits and compatible walking/running,
biking, surfing/diving, fishing, watering, field-move, decorating and riding frames.
Palette choices must stay separate from garment identity. Preserve all existing
save values and NPC rival palettes.

Generated with the built-in image tool from a reference sheet containing original
Aren/Aria fronts and Red's front as a clothing-only reference. No native art was
replaced. Prompt is saved alongside this file.
